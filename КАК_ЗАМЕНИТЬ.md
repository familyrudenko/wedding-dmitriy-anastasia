# Как заменить данные в приглашении

## Тексты, дата и адреса

Откройте `app/page.tsx`. В начале файла находятся два понятных блока:

- `ASSETS` — пути к фотографиям, видео, фону и музыке;
- `WEDDING` — имена, дата, дата для показа на странице и адреса.

Тексты разделов и расписание находятся чуть ниже в том же файле.

## Основные файлы

Все материалы лежат в `public/assets`.

| Что заменить | Файл |
|---|---|
| Видео на экране разблокировки | `unlock-video.mp4` |
| GIF-запасной кадр разблокировки | `unlock.gif` |
| Главная фотография | `hero-photo.png` |
| Музыка | `music.mp3` |
| Анимированный шелковый фон | `silk-video.mp4` |
| Статичный фон | `silk-frame.png` |
| Фото храма | `venue-2.jpg` |
| Фото ресторана | `venue-1.jpg` |
| Галерея образов | `dress-1.png`, `dress-2.jpg`, `dress-3.jpg`, `dress-4.jpg` |

Можно заменить файл новым с тем же именем — страницу редактировать не потребуется.

## Анкета

Сейчас анкета работает как демонстрация и показывает подтверждение на странице. Для реального сбора ответов её нужно подключить к вашей почте, Google Таблице или другому сервису.
